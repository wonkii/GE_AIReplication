## 개발 및 검증 사항

**목표:** 정확도·자연스러움·전송 비용의 관계를 공정하게 비교한다.

**실험 모드**

| 모드 | 전송 | 클라이언트 표시 | 확인할 효과 |
|---|---|---|---|
| `Default` | 기본 복제 | 기본 CMC | 원래 문제 크기 |
| `Adaptive` | Unreal 적응형 빈도 | 기본 CMC | 엔진 내장 최적화 |
| `AlwaysHigh` | 상시 고빈도 | 기본 CMC | 비용을 많이 쓴 정확도 상한 |
| `SingleShot` | 감지 후 1회 갱신 요청 | 기본 CMC | 첫 상태 전달의 효과 |
| `Burst` | 감지 후 짧은 고빈도 | 기본 CMC | 후속 갱신의 추가 효과 |
| `EventOnly` | Snapshot + 1회 갱신 | 기본 CMC | Snapshot 전송 비용 및 수신 시점 |
| `EventPredictor` | EventOnly와 동일 | 시각 예측 | 같은 전송에서 예측의 순수 효과 |

**측정 항목**

- 탐지: 지연, Precision/Recall, 오탐·미탐, Detector 실행 비용.
- 상태 정확도: 서버 궤적 대비 클라이언트 Capsule 오차의 peak/평균/시간 적분 및 회복 시간.
- 시각 품질: 서버 궤적 대비 Mesh 오차, 한 번의 보정 거리, Mesh 속도의 급변, 영상 비교.
- 네트워크: 연결별 총 bytes/s·packets/s, Enemy Actor·Snapshot·RPC의 비용, 실제 갱신 간격.
- 조건: Impulse 방향·세기, RTT 성분, 지터, 손실, AI 수, 기본 업데이트 빈도, 충돌 유무.

자연 설정값 비교와 별개로 **같은 측정 bytes/s 구간**의 방식끼리 오차를 비교한다. `NetUpdateFrequency` 설정값을 예산으로 간주하지 않는다. 반복 실행에서는 같은 시작 상태·Impulse·네트워크 조건을 사용하고, 평균뿐 아니라 worst case와 변동 폭도 보고한다. Networking Insights의 Packet/Net Stats 화면을 근거로 비용을 확인한다. [Networking Insights](https://dev.epicgames.com/documentation/en-us/unreal-engine/networking-insights-in-unreal-engine).

**최종 성공 기준:** `EventPredictor`가 `EventOnly`보다 동일 전송량에서 시각적 오차 또는 큰 보정을 줄이고, 안정적으로 기본 서버 상태에 복귀하면 사건 기반 예측의 기여를 주장할 수 있다. 반대로 차이가 없다면 그 결과를 인정하고, `SingleShot` 또는 `Burst`가 더 단순하고 효율적인 결론인지 제시한다.
