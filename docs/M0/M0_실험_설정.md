# M0. 실험 맵과 설정 고정

> 상태: M0 구현. [전체 아키텍처](../Architecture/Unreal_Sharp_Movement_마일스톤_구현계획.md) · 선행: 없음 · 다음: [M1](../M1/M1_서버_AI_복제.md)

기존 `GE_AIReplication.uproject`와 UE 5.8 설정을 유지하며 별도 실험 맵과 설정을 사용한다. M0에서는 모드와 식별자를 고정하지만, `Default`를 포함한 어느 모드도 아직 Enemy의 복제 주기나 CMC를 수정하지 않는다. 모드별 동작은 M1~M6에서 추가한다.

## 담당 파일과 폴더

아래 경로는 저장소 루트 기준이다. 파일이 기존 단계에서 생성되었다면 이 단계에서는 확장한다.

| 경로 | 역할 |
|---|---|
| `Source/GE_AIReplication/SharpMovement/Experiment/SharpExperimentTypes.h` | 실험 모드와 공통 식별자 |
| `Source/GE_AIReplication/SharpMovement/Experiment/SharpExperimentSettings.h/.cpp` | 실험 파라미터와 설정 에셋 타입 |
| `Source/GE_AIReplication/SharpMovement/Experiment/SharpExperimentManager.h/.cpp` | 실행 모드·RunId·TrialId 관리 |
| `Content/SharpMovementExperiment/Maps/SharpMovementExperiment.umap` | 독립적인 실험 장면 |
| `Content/SharpMovementExperiment/Blueprints/BP_SharpExperimentManager.uasset` | 장면의 실험 관리자 |
| `Content/SharpMovementExperiment/Data/DA_SharpExperimentSettings.uasset` | 설정 에셋 |

## 개발 및 검증 사항

**목표:** 다른 사람이 같은 장면과 네트워크 조건을 재현할 수 있는 뼈대 만들기.

**구현 작업**

1. 기존 UE 5.8 C++ 프로젝트 안에 `Content/SharpMovementExperiment/Maps/SharpMovementExperiment.umap`을 만든다. 현재 `ThirdPerson` 기본 맵 설정은 실험 실행 방법이 정해질 때까지 유지한다.

2. `SharpExperimentTypes.h`에 실험 모드를 정의한다: `Default`, `Adaptive`, `AlwaysHigh`, `SingleShot`, `Burst`, `EventOnly`, `EventPredictor`.

3. `SharpExperimentSettings`와 `DA_SharpExperimentSettings`에서 임계값, 평상시·고빈도 `NetUpdateFrequency`, 예측 최대 시간, 보정 시간, Impulse 벡터를 관리한다. 실행 시작 때 적용된 값을 로그로 남긴다.

4. `SharpExperimentManager`가 RunId·TrialId·모드를 고정하고 엔진 기본 Replication/CMC 경로를 변경하지 않은 `Default`를 보존한다.


**산출물:** 실험 맵, 모드·설정 목록, 서버·클라이언트 실행 방법. 프로젝트/엔진 버전은 [전체 아키텍처의 현재 프로젝트 상태](../Architecture/Unreal_Sharp_Movement_마일스톤_구현계획.md#0-현재-프로젝트-상태)에 기록되어 있다.

**완료 기준:** 같은 설정으로 서버와 클라이언트를 다시 실행했을 때 동일 모드를 선택할 수 있다.

## 구현된 실행 계약

맵에 `BP_SharpExperimentManager` 한 개가 배치된다. 서버가 시작할 때 `ConfiguredRunId`, `ConfiguredTrialId`, `ConfiguredMode`를 확정하고 `Identity` 구조체 하나로 클라이언트에 복제한다. 빈 RunId는 새 GUID로 채운다. 같은 실험을 반복하려면 RunId를 직접 지정한다. 명령줄의 `-SharpRunId=...`, `-SharpTrialId=...`, `-SharpMode=Default|Adaptive|AlwaysHigh|SingleShot|Burst|EventOnly|EventPredictor`가 배치된 Actor의 값을 덮어쓴다. 잘못된 모드 문자열은 오류로 기록하고 Actor에 설정된 모드를 사용한다.

`DA_SharpExperimentSettings`에는 속도 변화 임계값 300 cm/s, 방향 변화 45도, 평상시 10 Hz, 고빈도 60 Hz, 최대 예측 0.15초, 보정 0.10초, Impulse `(0, 700, 250)`이 초기값으로 들어간다. 이 값들은 이후 단계에서 사용할 실험 입력이며 M0에서 게임 이동에 적용되지 않는다. 시작 로그에는 서버와 클라이언트 각각 RunId, TrialId, Mode, 설정 에셋 이름 및 모든 수치가 출력된다.

## 서버·클라이언트 실행 예시

UE 5.8의 `UnrealEditor.exe`가 설치된 환경에서 PowerShell 창을 각각 열어 실행한다. `project` 변수는 로컬 프로젝트 경로로 바꾼다. 서버와 클라이언트는 같은 프로젝트 에셋을 사용해야 한다.

```powershell
$editor = 'C:\Program Files\Epic Games\UE_5.8\Engine\Binaries\Win64\UnrealEditor.exe'
$project = 'C:\path\to\GE_AIReplication.uproject'
$map = '/Game/SharpMovementExperiment/Maps/SharpMovementExperiment'
& $editor $project $map -server -game -log -port=7777 -SharpRunId=M0-replay-01 -SharpTrialId=1 -SharpMode=Default
```

```powershell
& $editor $project 127.0.0.1:7777 -game -log -windowed -ResX=960 -ResY=540
```

두 번째 클라이언트도 마지막 명령을 새 창에서 실행한다. 서버 로그의 `LogSharpExperiment`와 클라이언트 로그에 동일한 RunId, TrialId, Mode가 찍히는지 확인한다. 동일 모드의 반복 실행에는 `SharpRunId`, `SharpTrialId`, `SharpMode`를 고정한다. 맵 에셋은 시작 맵으로 지정하지 않았으므로 기존 ThirdPerson 기본 맵은 그대로 유지된다.

에셋을 재생성해야 할 때는 UE 에디터를 닫고 `UnrealEditor-Cmd.exe <uproject> -ExecutePythonScript=<repo>/Scripts/GenerateM0Assets.py -unattended -nullrhi`를 실행한다. 스크립트는 없는 에셋을 생성하고, 기존 맵의 관리자 설정 연결을 다시 저장한다.
