# GE_AIReplication

Developed with Unreal Engine 5

`Lv_Jang`의 Player 공격과 Sharp Enemy Root Motion 피격은 [실행·컴포넌트 확장 안내](docs/RootMotion_피격_벽충돌_기준선/04_공격피격_실행.md)를 참고한다. 전용 테스트 Character/레벨은 공통 컴포넌트와 인터페이스로 통합했다.

팀원 및 자동화 도구의 작업 결과는 [Saved 결과물 관리 규칙](docs/Legacy/Workflow/Saved_결과물_관리.md)에 따라 작업별 폴더와 `README.md`를 함께 생성한다. 저장소 작업 지침은 [AGENTS.md](AGENTS.md)에 있다.

패키징된 Host/Client의 LAN 서버 생성, 주소 확인 및 명시적 접속은 [LAN 서버 접속 안내](docs/Legacy/Architecture/LAN_서버_접속.md)를 참고한다.

PR 통합 내용, 에디터 테스트 순서와 작업자별 다음 단계는 [PR 통합 요약](docs/Legacy/PR_통합_요약.md)을 참고한다.

다중 Enemy Spline 이동과 급변 네트워크 실험의 설정·기록·예측·반복·보고서 사용법은 [실험 기능 안내](docs/Legacy/Architecture/SharpMovement_실험기능.md)를 참고한다.
